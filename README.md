# سیستم مدیریت نصرالله فرنیچر

سیستم مدیریت یکپارچه (ERP) برای مبلمان نصرالله

## تکنولوژی‌ها
- React + TypeScript + Vite
- Tailwind CSS + DaisyUI
- Neon PostgreSQL
- Vercel Serverless Functions

## نصب و اجرا

```bash
npm install
vercel dev
```

## متغیرهای محیطی
```
DATABASE_URL=postgresql://...
```
